ℹ️ Tentang Aplikasi

Aplikasi KORWIL VII DARANGDAN-BOJONG ini dirancang untuk membantu pendataan dan monitoring ketercapaian kemampuan membaca peserta didik di wilayah kerja Korwil Kecamatan Darangdan dan Bojong.


Fitur Utama:

  • ✅ Input data maksimal 60 sekolah
  • ✅ Validasi otomatis: total kriteria harus sama dengan jumlah siswa
  • ✅ Perhitungan persentase otomatis per kriteria
  • ✅ Indikator warna MERAH jika total kriteria melebihi jumlah siswa
  • ✅ Export data ke format Excel (.xlsx) dan CSV
  • ✅ Data tersimpan otomatis di browser (localStorage)
